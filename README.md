# Employment Portfolio

A nine-to-five version of Nick Gersbach’s freelance portfolio. Plain HTML, CSS, and JavaScript. No build or installation required.

## Files
- index.html: portfolio content and YouTube setting
- style.css: shared styles and responsive layouts
- app.js: mobile navigation and YouTube embed
- resume.html: editable résumé starter with print styles
- img/: project screenshots, favicon, and social icons

## Preview
Open index.html directly, or use VS Code Live Server. Use a local web server or hosting for YouTube playback. Google Fonts requires an internet connection; Arial is the fallback.

## Personalize before applying
1. Replace Nick’s name, location, email, biography, and all profile links in index.html and resume.html.
2. List only skills you can demonstrate. Tailor the introduction and skills to the responsibilities in each job description.
3. Replace the three project screenshots, both live links per project, alt text, and descriptions. Explain your role, the actual tools used, and a specific implementation challenge. Keep concept work labeled honestly. Add a View code link only when you have a suitable public repository you are allowed to share. Never publish secrets or private client code.
4. Add your verified employment history, dates, education, and achievements to resume.html. The supplied résumé starter contains Nick’s known profile and independent work; it is not a complete employment history. Print it to PDF from your browser if desired. To use your existing PDF instead, add it beside index.html and replace BOTH resume.html links in index.html with its exact filename.
5. Set data-youtube-url in index.html to your introduction video URL or 11-character video ID. Watch links, share links, embed URLs, Shorts and live URLs are supported. The default is intentionally blank. Record a short introduction or project walkthrough about your skills and how you work. The rest of the portfolio should stand on its own.
6. Test every link, check desktop/tablet/phone layouts, and replace the favicon if desired.

The project descriptions do not claim paid client work or business results. No unverified project technology labels, employment dates, degrees, or public source-code links have been invented.

## Hosting
Upload the files and img folder together. Keep index.html, style.css, app.js, and resume.html at the same level. If an older version still appears, clear your host’s cache.

## Contact
Email buttons open the visitor’s email app with an employment inquiry. There is no backend form or message storage.
